# Trading System Lifecycle Journal

This directory records the user's journey building the trading system.

Use it to preserve:

- ideas,
- decisions,
- todos,
- daily progress,
- metrics,
- strategy observations,
- deployment incidents,
- lessons learned.

## Files

- `todos.md`: master todo list.
- `ideas.md`: raw ideas and future concepts.
- `decisions.md`: important decisions and why they were made.
- `metrics.md`: cumulative quantitative record.
- `daily/`: one note per day.
