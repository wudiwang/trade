# 灵感库 · 研究闭环 (Idea Lab)

灵感库不是图片墙，是一条**可循环的研究流水线**：一张原始图 → 一版策略 → 一次回测 → 一轮标注
→ 据标注迭代出下一版策略 → 再回测 → 再标注。每一轮都留痕，半年后翻回来能看清"我当初为什么信
这个、后来为什么不信了"。

> 之后，再这个基础上优化细节，你要把这个过程记录，记在这个模块里，迭代后的策略，会继续跑新的回测，

## 闭环

```
① 原始图 + 用户感悟
      ↓ Claude 据此写出 策略 v1
② 策略迭代 (v1 → v2 → v3 …)
      ↓ 用户选月份, 触发回测
③ 回测记录 (顶部: 期望/笔数/Claude结论建议 | 下面: 逐个触发点位的K线图)
      ↓ 用户逐张标注: 符合 / 不准(+该改哪条筛选语句)
   → 生成「标注记录」, 绑定到当前策略版本, 冻结
      ↓ Claude 据标注迭代出 v2 ──────┘ (回到②)
④ 结论
```

关键约束：**标注记录绑定策略版本并冻结。** v1 的标注不会因为 v2 出现而改变——否则就没法回答
"这条规则是被哪一批样本推翻的"。

## 数据模型

```
research/ideas/<序号>-<slug>/
  idea.md                    # 原始图 + 用户原话 + 假设 (已有)
  timeline.md                # 追加式研究日志 (已有)
  charts/                    # 原始截图 (已有)
  strategy/
    v1.md                    # 策略版本: 规则原文 + 可执行参数 + 从哪一版演化而来
    v2.md
  backtests/
    v1_2026-06.json          # 一次回测: 版本 + 时间范围 + 期望/笔数 + Claude结论建议 + 触发信号列表
  annotations/
    v1_2026-06.jsonl         # 该次回测的标注: 每条信号 符合/不准 + 理由 (追加式, 冻结)
```

回测时间范围**按月**，不跑全年（数据量与信噪比都不合适）。

## 明确做不到的事（不要含糊）

**从上传的截图自动识别出是哪个币、哪个时间 —— 做不到。** 那是图像识别。
替代口径：上传时由用户给出 `symbol` + `时间`（文件名形如 `2026-07-12_EDGEUSDT_5m.png` 时自动带出），
右侧据此画出那一刻的可切换周期K线图。左静态图 / 右动态图的效果一致，定位靠用户给坐标，不靠猜。

## 与已有机制的关系

- 看图器的「👍符合/👎不符合」打标 (`pattern_cases/labels.jsonl`) 是**全局审美打标**，不绑定灵感，
  保持原样不动。
- 灵感内的标注是**绑定策略版本的回测标注**，是另一套东西，存在灵感目录下。两者不要混。
