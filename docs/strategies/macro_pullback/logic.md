# Macro Pullback Strategy Logic

## 状态

- 策略：`macro_pullback`
- 线上状态：live
- 周期：5m、15m
- 方向：long、short（实盘是否成交仍受 `trade_direction` 闸门控制）

## 入场链路

1. 爆量扫出既有高低点并在限定 K 线内收回，形成 spring 或 UTAD。
2. 形成不破第一极值的 L2/H2，且两段结构满足成笔、幅度和回撤质量要求。
3. L2/H2 确认后出现沿预期方向突破右侧合并 K 极值的停顿 K。
4. 随后的实际入场 K 仍须延续该方向：
   - 二买：入场收盘不低于自身开盘，也不低于停顿 K 收盘。
   - 二卖：入场收盘不高于自身开盘，也不高于停顿 K 收盘。
5. 任一条件不满足则不生成信号；被取消的结构不会自动反向生成另一方向信号。

## 2026-08-31 边界说明

方向确认只解决“停顿后等待的一根 K 已经反向收回，系统仍按旧方向入场”的时间错位。
它不把局部反弹直接定义为买点，也不改变 H1/L1/H2/L2、止损、止盈、仓位和熔断规则。
